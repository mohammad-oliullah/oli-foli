# Product Requirements

## 1. Product Overview

Oli.dev is an interactive professional profile for Md. Oliullah Sarder.

It is designed to replace the conventional static developer portfolio with a structured, searchable, evidence-driven professional experience.

---

## 2. Target Users

### Recruiters

Need to quickly understand:

- Who Oli is
- Professional experience
- Primary technical skills
- Years of experience
- Relevant projects
- Contact information
- Resume

### Hiring Managers

Need deeper information:

- Engineering responsibilities
- Technical decisions
- Architecture
- Project complexity
- Problem-solving ability
- Production experience

### Engineers

May want to explore:

- Architecture
- Code
- Engineering notes
- Experiments
- Technical decisions
- Learning journey

---

## 3. Core User Journey

A recruiter should be able to understand the candidate within approximately 30 seconds.

Recommended flow:

```text
Overview
   ↓
Experience
   ↓
Relevant Projects
   ↓
Skills + Evidence
   ↓
Resume / Contact
```
