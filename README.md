# 🏗️ Project Philosophy

Olism intentionally avoids the typical:

```text

About
Skills
Projects

```

portfolio structure.

Instead, it is being developed as a **living engineering profile**.

The platform is intended to expose not only the final results, but also the thinking behind them.

```text

    ↓

    ↓
Engineering Notes
    ↓
Learning
    ↓

    ↓
Career Journey
```

The idea is to make the portfolio useful to:

- Recruiters
- Hiring managers
- Software engineers
- Developers
- Potential collaborators
- Myself
